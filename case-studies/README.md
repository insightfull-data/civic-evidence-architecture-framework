# Originating Case Study

The Civic Evidence Architecture Framework grew from the design of **Toronto Public Transit Service Pulse**, an independent civic product that translates public transit and community data into public evidence and controlled private experiments.

The accompanying PDF describes how the framework was applied across:

- Public, private, administrative, and sandbox product surfaces
- Evidence classification and semantic definitions
- Data acquisition, validation, normalization, and storage
- Bounded journey-agent workflows
- Security, privacy, quality, and resilience
- Usage-aware performance and cost decisions
- Experiment-to-public publication gates

The case study is architectural documentation only. It does not include platform source code, credentials, production schemas, internal endpoints, operational schedules, or proprietary implementation logic.

Toronto Public Transit Service Pulse is not an official TTC platform or TTC website.

See [Toronto Transit Platform Architecture Framework](toronto-transit-platform-architecture-framework.pdf).
