# Security Policy

## Scope

This repository contains public architecture documentation, diagrams, templates, and fictional examples. It is not a deployable application and does not contain production credentials or operational code.

## Reporting a concern

Please do not publish suspected security-sensitive information in a public issue. Use GitHub's private vulnerability reporting feature for this repository when available, or contact the repository owner through the profile-linked contact channel.

Include:

- The affected file or section
- Why the information may create risk
- Whether the concern involves a secret, personal information, or operational detail
- A suggested redaction or correction if known

## Public-content rules

Contributions must not include:

- Secrets or credentials
- Private or personal data
- Production endpoints or account identifiers
- Detailed security bypass instructions
- Non-public schemas or infrastructure topology
- Source material that the contributor does not have permission to share
